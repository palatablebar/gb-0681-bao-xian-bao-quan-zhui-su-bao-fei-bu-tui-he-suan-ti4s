# 样例场景

12份保单，每份都有基础投保与追溯加保。每三份中的第一份撤销指定加保，其他保单10月降低责任。P001全年3650.00元；P002的181、92、92天三段合计5030.00元，补缴1380.00元。脏批额外含完全重复、缺失保费、同版冲突、短行、空行与重复表头。legacy样例含GB18030中文与全角千分位。

重复送达场景：`clean.csv` 与 `legacy.csv` 逻辑内容相同（仅编码与全角千分位不同），先后以“柜面/线上”提交会归并为同一批次；`dirty.csv` 的行序调整不改变批次身份，但增删空行或改动金额会形成新批次。每次提交都可在接收台账查看渠道、文件名、接收时间、原文摘要与采用依据。
